# 一曝十寒

A personal publishing space, built for words and quiet experiments.

[Live](https://yuhhhy.cn)

## Stack

Vue 3 · Koa · MongoDB · Three.js · Rapier

## Develop

```bash
pnpm install
pnpm start
```

## Structure

```text
blog-client       web
blog-background   studio
```
